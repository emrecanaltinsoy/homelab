## Jellyfin, Plex, and Servarr Docker Setup

```bash
/docker
├── jellyfin
│   └── config
├── plex
│   ├── overseer
│   │   └── config
│   ├── plex
│   └── tautulli
└── servarr
    ├── bazarr
    ├── gluetun
    ├── jellyseerr
    ├── lidarr
    ├── nzbget
    ├── prowlarr
    ├── qbittorrent
    ├── radarr
    └── sonarr

/data
├── downloads
│   ├── nzbget
│   │   ├── completed
│   │   ├── intermediate
│   │   ├── nzb
│   │   ├── queue
│   │   └── tmp
│   └── qbittorrent
│       ├── completed
│       ├── incomplete
│       └── torrents
├── movies
├── music
└── shows
```
